# Starlight documentation

Starlight is a Go rewrite of [Th0rgal's satmux](https://github.com/Th0rgal/satmux), designed to improve high-latency network access using persistent connections to a ground server.

The Go client and server run independently of the experimental GL.iNet router integration.
